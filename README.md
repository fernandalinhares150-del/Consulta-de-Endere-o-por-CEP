# Consulta de Endereço por CEP

## Sobre o projeto

Este projeto foi desenvolvido para consultar endereços brasileiros
utilizando um CEP e uma cidade informada pelo usuário.

A aplicação utiliza a API ViaCEP para buscar os dados do endereço.

Depois da consulta, o sistema apresenta as informações disponíveis
e disponibiliza um link para abrir o endereço no Google Maps.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- API ViaCEP
- Google Maps
- Git e GitHub
